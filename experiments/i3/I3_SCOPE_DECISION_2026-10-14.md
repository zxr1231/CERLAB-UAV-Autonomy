# I3研究主线收敛决策：现有筛池关闭，保留一个受限搜索假设

2026-10-14。只读取已有数据/源码，未产生新路线、新可见集合或仿真实验。
本报告不修改V2 E1的LIMITED_POOL_VALUE_FAIL或其他冻结阶段结论。

## 决定

**停止继续调当前几何5分层池；不进入E2或在线算法。** 主要论文贡献仍未成立。
可保留一个、也只保留一个后续可证伪假设：

> 用参考路线的观测集合条件化候选的乐观观测上界，在完整精评分前改变候选访问与
> 保留顺序，在相同有限母集、精评分额度、运动和wall预算内找到更有价值的路线。

推荐以后安排一次G1最小机制验证，而非继续换anchor/Edge表示、增加权重或重跑seed。
本轮完成的是决策和数学机制草案，G1尚未登记为可执行实验、尚未编码、尚无性能结论。
若该唯一假设不通过其后预先冻结的对照门槛，关闭/降低这一主创新主张，不再无限校准。

## 2. 主要贡献的当前定位

- 路径去重/局部精确合成：保留为基础评价机制，正确性已支持；不宣称独立提升探索效率。
- 观测引导候选搜索：唯一继续讨论的主要贡献候选，尚未实现/支持。
- 保留via Edge：公共表示约束，不是已验证的观测保留简化算法。
- Edge cache：不加入本假设；当前没有在线预算和复用率依据。

以后如形成贡献，应描述具体的参考观测条件化界、预算下选择行为及执行证据，不能用
“首次路径gain/首次union/首次信息插点/首次缓存”或强凑三个独立创新点。

## 3. 唯一待验证机制：参考条件观测上界引导的候选搜索

### 3.1 保持表示，改变池锁定前的信息使用

公共母集S固定为E1已保存的ordered合格走廊，大小0/1/52/126/2。既定map、Goal、motion、
camera和参考不变。不新增几何路线、不扩大最终<=5精评分池、不去掉真实Edge约束。
G1以后若用于新快照，同样固定几何规则和操作上限；当前设计不授权采集新快照或seed。

旧机制先按time取5分层再camera；新机制在这5条精评分路线确定前，读取参考集合R，
对整个有限S做便宜的观测上界查询，再选择/访问候选。因此新增的是**观测条件筛选/搜索**，
不是假装参考集合产生了新的连续空间几何路径。候选几何草图本身仍由成熟框架提供。

### 3.2 残余Unknown集合与保守几何包络

R=参考路线预测可见Unknown集合，N=快照中planning region内Unknown地址，Q=N\R。
N和R是当前冻结预测模型中的量，不是actual observation，也不代表完整SLAM熵。

对每走廊，changed window的位置在其至多三条连接/Edge段及端点旋转上。对这些段取
axis-aligned bounding boxes，并向各轴扩张：

```text
rho = raycast_max_range + ||body_to_camera_translation|| + sqrt(3)*map_resolution
```

末项是保守的一个体素全对角余量，涵盖ray穿越体素中心与浮点边界影响；正式实现仍须
验证该界对本模型的所有测试成立。忽略FoV/Occupied遮挡会让界变松，但不应漏掉可见体素。
出口旋转在同一端点，包含在上述位置包络内。

在Q上建立一次可计费的3D前缀计数表，查询每个盒中的体素数。可使用精确盒union，或
保守的min(|Q|,sum(box_counts))作为K(tau)，不把重复盒计数当真实新增观测。
参考R、计数表、构建/分配和查询全部计入wall、访问和256MiB scratch，不预设为免费。

如果changed window的新可见体素确实被包络涵盖，则：

```text
|V(tau) minus R| <= K(tau)
|V(tau)| <= |R| + K(tau)
U(tau) <= Ubar(tau) = (|R| + K(tau)) / T(tau)
```

T(tau)是原模型已算出的正估计代价；此界不忽略代价。它允许忽略lost作乐观估计，
最后仍用精确B_e union C同时计算new/lost/时间。不能把Ubar当真实gain或负A*边权。
若参考之外的pose并未保持不变，包络证明前提失效；必须拒绝该候选，不能用松界掩盖错误。

### 3.3 有限访问与停止

- 从reference的精确U0开始，按Ubar从高到低访问母集，完全同分用原(time,length,u,v,e)。
- 每访问一条走廊才计算其changed pose可见集合与精确U，最多5条精评分，保持独立history。
- 若尚未评价的最大Ubar<=当前最好精确U+1e-9，可在所定义有限母集范围内给出容差内
  停止证书。若达到5条或wall限额而界仍大，记录uncertified，不称母集最优或全局最优。
- 任何必需评分超时/invalid遵守V2全有或全无与回退规则；partial结果不参与选择。
- R始终是reference集合。不能把某条候选的可见集合并入R去改变其他互斥路线的history。

这不是宣称全局PRM探索最优；只是在一个有限公共母集上，用同一精确评价器选择哪几条
值得优先计算。界如果过松，搜索很可能退化为另一种无效排序，这也是需要证伪的风险。

## 4. 公平对照与有限退出条件（待后续冻结执行协议）

只保留以下三种筛选/访问规则，最后统一使用同一精确评价器和reference回退：

1. geometry-stratified：当前5代价分层规则，作为冻结失败分支的对照。
2. unconditioned-bound：同包络/访问机制，但查询N而非N\R；保留运动代价，隔离reference
   条件化的作用。不能把它称作外部SOTA，也不能额外故意削弱。
3. reference-conditioned-bound：查询Q=N\R的上述机制。

共同S、Goal、运动约束、最终精评分cap5和资源上限；完整核算各自实际成本。不同方法
最终候选可以不同，这是生成/筛选比较的必要条件。严格等精评分数的机制比较与早停的
预算效率比较分别报告；不通过复制路线填数，不把同cap当成同实际完成数。

后续G1协议须在运行前冻结代码、输入和界的数值/边界规则。建议保留一次批次，先验证界
对实际被评分候选不低估，再检查：

- 按原阶段和安全规则留档，source/hash/合成正确，无新物理参数和候选填充。
- reference条件化确实在精评分池锁定前改变候选访问，不是最终数字重排序。
- 至少2个状态得到正精确U；至少1状态严格优于几何规则、至少1严格优于不条件化界规则，
  五状态平均effective U不低于二者。1e-9只是数值容差，不能当论文效应大小。
- 同时保持500ms问题待独立完整计费解决；界/table准备若无法纳入预算，不增预算或加入
  持久cache补救，不将少查询次数直接叫真实加速。

G1采集前必须补齐模型allocated capacity及全进程峰值RSS记录，采用独立分配计量和
进程资源统计；不能再次只有逻辑payload。所有prefix/table查询次数、内存与序列化成本
须分项保存。旧E1缺口保留，不重跑旧实验补数。

没有满足这些条件就结束这个唯一假设，不再增加pool/seed、换point/edge或调多个权重。
满足也仅是相关开发快照的有限信号，不能复用已公开状态26/38的结果当独立验证。
进一步论文验证必须另登记未用于设计的场景/快照和闭环试验；本轮不执行或自动授权。

## 5. 创新性审查：不能把标准搜索技术当新理论

分支定界已用于IPP，作者页面直接介绍单调目标下的信息路径搜索；本假设不能宣称首次
用信息上界或惰性评价。[Binney与Sukhatme，ICRA 2012作者页面](https://robotics.usc.edu/publications/747/)

2026覆盖型IPP已有边际覆盖与路径增量联合选择；本机制不同的可研究点只能是UAV的
reference条件3D可见集上界、局部精确替换、实际观测与严格预算，而不是通用
“新增观测/绕行代价”概念。[Jakkala等原文§V-D/附录C](https://arxiv.org/html/2602.05198v1)

ETH作者框架已经具备轨迹可见体素和父链去重代码，默认选项及其论文假设要区分；
本项目不能把path-history本身再次当主要创新。[作者computeGain](https://raw.githubusercontent.com/ethz-asl/mav_active_3d_planning/master/active_3d_planning_core/src/module/trajectory_evaluator/simulated_sensor_evaluator.cpp)

此机制目前创新性风险仍高。没有证明它达到普通SCI/EI贡献强度；只有与强同机制对照的
实际稳定差异和多场景执行证据，才可能使成熟思想形成针对明确缺陷的方法贡献。
